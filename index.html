Regular Expressions for Bioinformatics

Regular expressions are used to describe patterns in sequences of symbols. In bioinformatics, these patterns can help identify specific arrangements of amino acids in proteins or nucleotides in DNA.

This project demonstrates how regular expressions can be applied to five biological problems: protein motif mimicry detection, protein modification site identification, regulatory DNA motif detection, DNA restriction site identification, and RNA start codon identification.

  • Understand biological alphabets and sequences.
  • Learn how regular expressions describe patterns.
  • Test patterns against biological sequences.
  • Upload your own DFA or NFA diagrams.
Explore the applications

A pattern match is a useful clue, not proof of biological function.

Quick Guide

  • Alphabet (Σ): A finite set of symbols used to form strings. DNA uses Σd = {A, C, G, T}. Protein sequences use the 20 standard amino-acid symbols.
  • String: A sequence of symbols from an alphabet. For example, ACGT is a DNA string.
  • Union (+): Choosing between alternatives. For example, A + C means either A or C in formal TOC notation.
  • Concatenation: Patterns appear one after another. For example, AC means A followed by C.
  • Kleene star (*): Zero or more repetitions. For example, A* includes ε, A, AA, AAA, and so on.
  • Empty string (ε): A string containing no symbols.
  • DFA: A deterministic finite automaton with one next state for each state and input symbol.
  • NFA: A nondeterministic finite automaton that can have multiple possible next states.

Formal TOC notation and programming regex syntax (used by the testers here) are related ways of describing patterns, but they are not identical in every detail. For example, [AT] in programming syntax corresponds to A + T in formal notation.

Application 1

Protein Motif Mimicry Detection

Proteins are chains of amino acids. A protein motif is a short, recognizable pattern in a protein sequence. Sometimes a pathogen protein contains a pattern resembling one found in a host protein. Finding a similar pattern can help researchers investigate possible molecular mimicry. However, a matching pattern alone does not prove that the proteins have the same function or that mimicry is occurring.

Objective

Identify protein sequences containing a specified amino-acid pattern using a regular expression.

Alphabet

Σp = {A, C, D, E, F, G, H, I, K, L, M, N, P, Q, R, S, T, V, W, Y}

Regular expression

[KR].{1,2}[ST].{1,3}[LIV]
  • [KR] — The first matched character must be K or R.
  • .{1,2} — The next part contains one or two characters.
  • [ST] — The next specified position must be S or T.
  • .{1,3} — The next part contains one to three characters.
  • [LIV] — The match ends with L, I, or V.

The dot and repetition syntax above uses programming-regex conventions.

Worked example

Input: MAKASALPQ → Expected match: KASAL

  • K satisfies [KR].
  • A satisfies the first wildcard segment.
  • S satisfies [ST].
  • A satisfies the second wildcard segment.
  • L satisfies [LIV].
  • The entire substring KASAL matches the expression.

Why is this useful?

  • Searches long protein sequences for specified patterns.
  • Provides a first screening step for candidate motifs.
  • Demonstrates how biological rules can be represented as regular expressions.
  • Illustrates pattern recognition from Theory of Computation.

Try it yourself

[KR].{1,2}[ST].{1,3}[LIV]

Application 2

Protein Modification Site Identification

Proteins can undergo chemical changes after they are produced. These changes are called post-translational modifications. One example is phosphorylation , in which a phosphate group is added to a molecule such as a protein. Phosphorylation commonly involves the amino acids serine (S), threonine (T), and tyrosine (Y).

A regular expression can locate these amino acids in a protein sequence. Finding one does not confirm that phosphorylation actually occurs.

Objective

Find candidate positions containing amino acids commonly associated with phosphorylation.

Alphabet

Σp = {A, C, D, E, F, G, H, I, K, L, M, N, P, Q, R, S, T, V, W, Y}

Regular expression

[STY]
  • [STY] — Matches exactly one character: S, T, or Y. S = serine, T = threonine, Y = tyrosine. Each match is a candidate position for further investigation, not a confirmed modification site.

Worked example

Input: MACKSTYAL → Expected match: S, T and Y

  • All three symbols match because each is an allowed character in [STY].

Why is this useful?

  • Identifies occurrences of selected amino acids.
  • Helps screen sequences for candidate positions.
  • Demonstrates how a short regex can recognize a biological feature.
  • Provides a simple example of sequence scanning.

[STY]

Application 3

Regulatory DNA Motif Detection

DNA contains instructions that help control how genes work. Some proteins bind to specific DNA regions and influence gene expression. A regulatory DNA motif is a short sequence pattern that may be recognized by a regulatory protein.

Researchers can search DNA sequences for candidate motifs and compare their occurrence across different organisms. A pattern match alone does not prove that a region regulates a gene.

Objective

Find DNA sequences containing a specified nucleotide pattern.

Alphabet

Σd = {A, C, G, T}

Regular expression

TATA(A+T)A(A+T)
  • TATA — These four nucleotides must appear in order.
  • [AT] — The next nucleotide can be A or T.
  • A — The following nucleotide must be A.
  • [AT] — The final nucleotide can be A or T.

Worked example

Input: GCTATAAAAGC → Expected match: TATAAAA

  • The substring starts with TATA, followed by A, A, and A. These positions satisfy the pattern.

Why is this useful?

  • Searches DNA for a specified nucleotide pattern.
  • Helps compare candidate motifs across sequences.
  • Demonstrates regular expressions on a four-symbol alphabet.
  • Illustrates formal pattern recognition in biology.

Try it yourself

TATA(A+T)A(A+T)

Application 4

DNA Restriction Site Identification

Restriction enzymes are proteins that recognize specific DNA sequences and cut DNA at or near those locations. These enzymes are commonly used in genetic engineering and molecular biology. For example, the restriction enzyme EcoRI recognizes the DNA sequence GAATTC. A regular expression can help locate this sequence in a longer DNA string.

Objective

Identify DNA sequences containing a specific restriction enzyme recognition site using a regular expression.

Alphabet

Σd = {A, C, G, T}

Regular expression

GAATTC
  • G — The first nucleotide must be G.
  • A — The second and third nucleotides must be A.
  • T — The fourth and fifth nucleotides must be T.
  • C — The final nucleotide must be C.

Worked example

Input: CCGGAATTCTTA → Expected match: GAATTC

  • The substring GAATTC appears in the input sequence.
  • All six nucleotides match the required pattern.

Why is this useful?

  • Identifies restriction enzyme recognition sites.
  • Helps locate specific DNA cutting regions.
  • Demonstrates exact sequence matching using regular expressions.
  • Provides an example of pattern recognition in genetic engineering.

Application 5

RNA Start Codon Identification

RNA contains genetic information used by cells to produce proteins. Protein synthesis generally begins at a start codon. The most common start codon is AUG, which codes for the amino acid methionine. A regular expression can locate AUG occurrences in an RNA sequence. Finding AUG alone does not confirm that translation actually begins at that position.

Objective

Identify potential start codons in an RNA sequence using a regular expression.

Alphabet

Σr = {A, C, G, U}

Regular expression

AUG
  • A — The first nucleotide must be A.
  • U — The second nucleotide must be U.
  • G — The third nucleotide must be G.
  • AUG — Represents the common start codon in RNA.

Worked example

Input: CCGAUGGCUAUG → Expected matches: AUG and AUG

  • The first AUG appears at positions 4–6.
  • The second AUG appears at positions 10–12.
  • Both occurrences match the required pattern.

Why is this useful?

  • Identifies potential start codons in RNA sequences.
  • Helps locate candidate protein translation starting positions.
  • Demonstrates exact sequence matching using regular expressions.
  • Provides a simple example of pattern recognition in molecular biology.

Glossary

Amino acid
A building block that joins with others to form a protein.
DNA nucleotide
One of the four DNA symbols A, C, G, and T.
Motif
A short, recognizable sequence pattern that may be biologically meaningful.
Regular expression
A formal way to describe a set of strings or sequence patterns.
Pattern matching
Checking whether a sequence contains a substring that follows a specified rule.
DFA
A deterministic finite automaton.
NFA
A nondeterministic finite automaton.
Accepting state
A state representing successful recognition of a pattern under the automaton's rules.
Phosphorylation
A chemical modification involving the addition of a phosphate group.
Biological candidate
A sequence that matches a pattern but still needs biological validation.
